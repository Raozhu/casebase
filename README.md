# casebase

A stripped macOS top overlay shell renamed to `casebase`.

## What Remains

- A single floating top overlay window
- The original black notch-style shell
- Hover to expand, leave to collapse

## What Was Removed

- App switching
- Search
- Notifications
- Tray
- Timer
- Settings
- Hotkeys
- Accessibility automation
- Updater
- All Swift Package dependencies

## Build

Open `casebase.xcodeproj` and run the `casebase` target.
